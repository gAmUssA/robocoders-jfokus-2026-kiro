# Product Overview

The Shelly IoT Color Picker is a live conference demonstration application for JFokus 2026. It captures the dominant color from a webcam feed in real-time and transmits it to a Shelly Gen1 IoT smart bulb, creating a visual demonstration of color extraction and IoT integration.

## Key Features

- Real-time webcam color capture and analysis
- Live IoT bulb control via HTTP API
- Manual fallback mode for reliability
- Audience-friendly visual feedback
- Graceful error handling for live demos

## Target Audience

Conference attendees at JFokus 2026 watching a live technical demonstration.

## Success Criteria

- Reliable operation during live presentation
- Clear visual feedback visible from back of room
- Graceful degradation when hardware fails
- End-to-end latency under 500ms
